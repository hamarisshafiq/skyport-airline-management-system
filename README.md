# Skyport – Airline Reservation & Tour Management System

A Java-based desktop application developed using Object-Oriented Programming, Data Structures, Database integration, and GUI concepts. The system provides complete airline reservation and tour management functionalities through separate Admin and User panels.

## Technologies Used
- Java
- OOP
- Data Structures
- Database
- GUI

## Features

### Admin Panel
- Manage flights and airline records
- Add and manage hotels and tours
- Monitor booking information
- Manage system data and operations

### User Panel
- Search and book flights
- Explore available tours and hotels
- Generate booking tickets
- View reservation details through interactive GUI

## System Highlights
- Database-integrated desktop application
- User-friendly graphical interface
- Secure and organized data management
