# Skyport – Airline Reservation & Tour Management System

A Java-based desktop application developed using Object-Oriented Programming, Data Structures, Database integration, and GUI concepts. The system provides complete airline reservation and tour management functionalities through separate Admin and User panels with an interactive graphical interface.

---

# Technologies Used

- Java
- OOP (Object-Oriented Programming)
- Data Structures
- Database Integration
- Java GUI

---

# System Modules

## User Panel

The user panel allows customers to explore and manage travel-related services through an interactive interface.

### Features
- User authentication system
- Flight search and booking
- Tour package exploration
- Hotel reservation management
- Ticket generation functionality
- Booking history and reservation details

---

## Admin Panel

The admin panel provides complete management and control over the system.

### Features
- Manage flights and airline records
- Add and manage hotels
- Add and manage tour packages
- Monitor booking information
- Manage overall system operations
- Database record management

---

# System Highlights

- Interactive GUI-based desktop application
- Database-driven architecture
- Organized Admin and User dashboards
- Efficient booking and reservation management
- User-friendly interface design
